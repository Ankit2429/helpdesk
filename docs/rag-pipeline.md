# Local RAG Pipeline

`create_rag_pipeline(settings)` assembles the local ingestion and retrieval
components from typed application settings. It does not make model or index
calls until a method is invoked.

```python
from pathlib import Path

from campus_helpdesk.config.settings import get_settings
from campus_helpdesk.infrastructure.rag.factory import create_rag_pipeline

pipeline = create_rag_pipeline(get_settings())
pipeline.ingest_pdf(Path("data/knowledge/campus-handbook.pdf"))
results = pipeline.search("Where is the admissions office?")
```

The PDF loader uses LangChain, chunking uses the configured recursive splitter,
embeddings are generated locally with Sentence Transformers, and FAISS persists
the index under `FAISS_INDEX_PATH`. Source PDFs must be located under
`KNOWLEDGE_SOURCE_PATH`; this prevents traversal outside the knowledge corpus.
`KNOWLEDGE_MAX_FILE_SIZE_BYTES` bounds individual input-file memory pressure.
Scanned PDFs require an OCR preparation step before ingestion.

The embedding model must be provisioned in `EMBEDDING_MODEL` before deployment.
`EMBEDDING_LOCAL_FILES_ONLY=true` prevents model downloads at runtime. Load only
indexes generated by this trusted local application. Set
`FAISS_ALLOW_DANGEROUS_DESERIALIZATION=true` only for such trusted indexes,
because FAISS metadata persistence uses deserialization. Changing
`EMBEDDING_MODEL` or `EMBEDDING_NORMALIZE` requires rebuilding the FAISS index.
